Arquitectura Completa — MappingAndroid

Aplicación Android de video-mapping en tiempo real con soporte multi-dispositivo (Servidor/Cliente), renderizado OpenGL ES 2.0, sincronización de estado por WebSocket y emulador Nanoleaf para integración con controladores DJ.

Jetpack Compose ExoPlayer / Media3 GLSurfaceView FBO Multi-layer NanoHTTPD UDP Discovery Hilt DI 27+ GLSL Shaders Nanoleaf Emulator CameraX → MJPEG Undo/Redo (50 steps) Crash Recovery

01 Estructura de Módulos Gradle

El proyecto se divide en dos módulos: :app contiene toda la lógica Android, y :mapping-core es una librería Kotlin pura sin dependencias del framework Android.

11 Persistencia y Recuperación de Crashes

Sistema de doble checkpoint: estado actual tras cada operación + estado estable cada 30s. Ante un crash, Application.onCreate() hace rollback automático antes de que arranque cualquier ViewModel.

11b Nanoleaf Emulator — Integración DJ

Sistema de emulación Nanoleaf que permite a controladores DJ (Numark/Engine OS) enviar datos de color via UDP. El emulador registra un servicio mDNS, expone un HTTP API compatible, y alimenta un shader GLSL con los 16 colores de paneles en tiempo real.
